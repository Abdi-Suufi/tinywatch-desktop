## Features

- **Clean desktop window.** Tinywatch in its own app, with a slim title bar that matches the site and follows your system's light or dark mode.
- **Fewer popups.** Blocks popup windows and known ad requests from embedded players.
- **Discord status.** Shows on your Discord profile what you're watching, the season and episode, and how far in you are.
- **Automatic updates.** New versions download in the background and install when you restart the app.
- **Always up to date.** Website updates appear instantly, with no new download needed.

## Install

1. Open the [latest release](https://github.com/Abdi-Suufi/tinywatch-desktop/releases/latest).
2. Download **Tinywatch-Setup-x.y.z.exe** and run it.
3. Windows may show a **"Windows protected your PC"** warning because the installer isn't code-signed. Click **More info**, then **Run anyway**.

Already installed? The app updates itself, so you don't need to download anything again.

**Platform:** Windows only for now.
